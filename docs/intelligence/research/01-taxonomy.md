# Design-System-Taxonomie

Kanonische Struktur für Research, Rules und Skills. Jede Observation, jedes Principle und jede Rule wird einer oder mehreren Kategorien zugeordnet.

## 01 Foundations

| Subtopic | Fokus |
| --- | --- |
| Color | Palette, Semantic Color, Modes, Contrast Roles |
| Typography | Scale, Roles, Pairing, Readability, Truncation |
| Spacing | Scale, Rhythm, Density Modes |
| Grid | Columns, Gutters, Margins, Breakpoints |
| Sizing | Control Heights, Icon Sizes, Hit Areas |
| Radius | Consistency, Semantic Radius |
| Elevation | Shadow / Surface Layers, Depth Semantics |
| Iconography | Metaphor, Optical Balance, Size Tokens |
| Motion | Duration, Easing, Reduced Motion, Purpose |

## 02 Layout

| Subtopic | Fokus |
| --- | --- |
| Containers | Max-width, Padding, Nested Surfaces |
| Columns | Composition, Asymmetry, Alignment |
| Alignment | Optical vs Mathematical |
| Density | Comfortable / Compact / Sparse |
| Hierarchy | Primary / Secondary / Tertiary Scan Paths |
| Responsive Behavior | Reflow, Stack, Collapse, Hide |

## 03 Components

Buttons, Inputs, Selects, Checkboxes, Radio Buttons, Cards, Tables, Tabs, Navigation, Modals, Tooltips, Dropdowns, Toasts, Alerts, Badges, Avatars, Pagination Controls, Steppers.

Pro Komponente immer erfassen:

- Anatomy
- Variants
- States (default, hover, focus, active, disabled, loading, error, success)
- Composition rules
- Do / Don't
- A11y requirements
- Content guidelines

## 04 Patterns

Forms, Search, Filtering, Pagination, Onboarding, Authentication, Checkout, Dashboards, CRUD, Empty States, Error States, Loading States, Permissions / Empty Permission, Multi-step Flows.

## 05 UX

Information Architecture, User Flows, Interaction Design, Feedback, Affordance, Cognitive Load, Progressive Disclosure, Error Prevention, Recognition over Recall.

## 06 Accessibility

WCAG Mapping, Keyboard Navigation, Screen Readers, Focus Management, Contrast, Touch Targets, Motion Sensitivity, Semantic HTML / Roles, Alternative Text, Live Regions.

## 07 Content Design

Labels, Microcopy, Error Messages, Empty States, CTAs, Information Hierarchy in Copy, Tone vs Clarity, Localization Constraints.

## 08 Responsive Design

Breakpoints, Fluid Layouts, Mobile-first, Adaptive Components, Touch Interaction, Thumb Zones, Safe Areas.

## 09 AI UI

Chat, Copilots, Generative UI, Streaming, AI States (thinking / partial / complete / failed), Confidence Display, Citations, Human-in-the-loop, Agent Interfaces, Tool Call Visibility, Undo / Regenerate.

## Querschnittliche Dimensionen

Zusätzlich zu den 9 Domains jede Rule mit diesen Facetten taggen:

- **Product type:** B2B / B2C / Consumer / Enterprise / Marketplace / Creator Tool
- **Density:** Sparse / Default / Dense
- **Platform:** Web / iOS / Android / Desktop / Cross-platform
- **Evidence class:** Opinion / Heuristic / Standard / Empirical / System Convention
- **Maturity:** EXPERIMENTAL / CANDIDATE / CORE / DEPRECATED
