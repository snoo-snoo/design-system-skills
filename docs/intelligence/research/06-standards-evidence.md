# Standards & empirische Evidenz

Ankerquellen, die Confidence-Upgrades erlauben — unabhängig von Social Content.

## Accessibility (P0)

| Standard / Quelle | Was es legitimiert | Mapping |
| --- | --- | --- |
| WCAG 2.2 | Contrast, Target Size, Focus, etc. | A11y Rules → CORE candidates |
| WAI-ARIA Authoring Practices | Correct widget behavior | Component interaction rules |
| WebAIM Contrast / Surveys | Practical a11y baselines | Validation checklists |
| EN 301 549 / local regs | Legal/compliance context | Constraints, not aesthetics |

## Usability Heuristics & Theory

| Quelle | Nutzen | Limitation |
| --- | --- | --- |
| Nielsen’s 10 Heuristics | Broad UX critique language | Not component specs |
| Norman: Affordances / Feedback / Mapping | Interaction foundations | Needs UI translation |
| Fitts’s Law | Target size / distance | Don’t overfit exact numbers without context |
| Hick’s Law | Choice complexity | Not a mandate to hide everything |
| Gestalt principles | Grouping / hierarchy perception | Easy to over-claim |

## Empirische Research Orgs

| Org | Starke Domains | Caution |
| --- | --- | --- |
| Nielsen Norman Group | IA, forms, content, mobile patterns | Sample/context dependence |
| Baymard Institute | Checkout, e-commerce forms | Commerce-biased |
| Academic HCI papers | Controlled findings | Transfer to product UI carefully |

## Evidence → Confidence Mapping

| Evidence Mix | Confidence |
| --- | --- |
| WCAG MUST + ≥1 reputable system alignment | **HIGH** |
| ≥3 independent systems OR ≥2 systems + strong heuristic | **HIGH** |
| 2 aligned sources, context-sensitive | **MEDIUM** |
| 1 educator opinion / aesthetic tip | **LOW** (Observation only) |
| Conflicting HIGH sources | Document contradiction; split by Context |
