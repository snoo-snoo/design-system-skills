# PRINCIPLE-TEXT-ALIGN-001 — Prefer Start Alignment for Multi-line UI Text

```text
Principle:
Avoid stacking multiple lines of center-aligned text in product UI; prefer
start (left in LTR) alignment for readable blocks.

Problem:
Centered multi-line text creates uneven alignment anchors and harder scanning.

Recommendation:
Use start alignment for body, lists, form copy, and multi-line descriptions.
Reserve centering for short headlines, single-line labels, or intentional
hero/empty-state titles.

Why:
Stronger vertical rhythm and faster reading.

Context:
Product UI layouts (web/mobile). Decorative marketing compositions differ.

Exceptions:
Short centered headings; poetry/quotes; single-line CTAs; mirrored RTL rules
(use logical start/end).

Evidence:
- VID-SAMPLE-005
- Established typography craft (alignment/scanability)

Confidence:
Medium–High

Category:
02 Layout / Alignment + 01 Typography

StatementClass:
Practice

Maturity:
CANDIDATE

PriorityFloor:
P2 information hierarchy / P5 craft
```
