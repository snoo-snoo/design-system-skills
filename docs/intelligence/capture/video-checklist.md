# Capture Checklist — Video / Reel / Talk Sources

Use for YouTube, conference talks, Instagram Reels, podcasts with UI demos.

## Before capture

- [ ] Stable URL + title + creator + publish date
- [ ] Duration and format (talk / tutorial / reel / interview)
- [ ] Credibility tier from `research/03-experts-creators.md`
- [ ] Primary Wave topics (A–D)

## Layer 1 — Transcription

- [ ] Full or high-coverage transcript (prefer official captions, then ASR)
- [ ] Mark: statements, recommendations, examples, justifications, caveats, counterexamples
- [ ] Timestamp key claims

## Layer 2 — Visual analysis

Document what is **shown**, independent of speech:

- Layout / grid / spacing
- Components and states
- Typography / color / icons
- Navigation / hierarchy
- Motion / responsive behavior
- Empty / loading / error if shown

## Layer 3 — Conflict check

- [ ] `SpeechVsVisual: aligned | conflict | partial | n/a`
- [ ] If conflict: describe both sides; do not resolve by preference

## Extraction discipline

- Default statement class for educator content: start as `Opinion` or `Practice` until cross-sourced
- Reels/tutorials alone cannot promote a rule to CORE
- Prefer official system channel videos when claiming system conventions

## Output

- Source Profile + analysis notes under `docs/intelligence/analysis/<SOURCE-ID>/`
- Link any Principle IDs created in Phase 3
