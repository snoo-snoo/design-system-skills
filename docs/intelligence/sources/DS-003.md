## Source summary

Shopify’s design system for admin and app surfaces. Notable for “when to use / when not to use”, content guidelines, and intentional token naming.

## Why it matters

- Best-in-class **content + usage** documentation for component rules
- Strong candidate for Forms, Feedback, Action hierarchy principles
- Token intent language useful for Foundations without copying Shopify values

## Priority analysis targets (Phase 2)

1. Foundations tokens (color/space/type) — principles, not raw values
2. Button / Banner / Form layout patterns
3. Content guidelines for errors and empty states
4. When-to-use sections as Decision Logic seeds
