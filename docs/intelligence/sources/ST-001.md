## Source summary

Canonical accessibility standard for web content. Four principles (Perceivable, Operable, Understandable, Robust), 13 guidelines, testable success criteria. Supporting docs (Understanding, Techniques, How to Meet) are informative companions.

## Why it matters for this project

- Primary **P0 evidence anchor** — can elevate compatible rules to CORE
- Defines testable baselines (contrast, target size, focus, etc.) that override aesthetic preference
- Maps cleanly to validation checklists in later skills

## Priority analysis targets (Phase 2)

1. New/changed 2.2 criteria vs 2.1 (esp. focus appearance, dragging, target size)
2. Conformance levels relevant to product UI (AA as default product bar)
3. Mapping of success criteria → Foundations / Components / Patterns taxonomy

## Evidence class default

`Standard` (normative). Techniques = informative unless elevated by other sources.

## Risks / caveats

- Does not cover every cognitive/learning need; supplemental guidance exists separately
- AAA is rarely a universal product mandate — document level explicitly per rule
