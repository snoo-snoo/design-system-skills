# Analysis — VID-SAMPLE-006 (Borders vs Whitespace Hierarchy)

## 1. Source Summary

Educator Reel: stop using lines/borders as the default way to create hierarchy. Too many borders make layouts feel like spreadsheets; the best layouts are held together by white space.
