# Checklist: ux

Functional clarity, feedback, and error prevention (Wave A scope).

| ID | Check | Severity | Notes |
| --- | --- | --- | --- |
| UX-01 | Primary actions are easy to find and activate (size/label/placement) | P1 | RULE-TOUCH-001 + clarity |
| UX-02 | Form fields explain purpose via visible labels | P0/P1 | RULE-FORM-LABEL-001 |
| UX-03 | Destructive modal confirms are hard to do by accident (initial focus choice) | P1 | RULE-DIALOG-001 |
| UX-04 | User can cancel/dismiss overlays (Esc + visible control) | P0 | RULE-DIALOG-001 |
| UX-05 | Tabbed content makes active panel obvious | P2 | RULE-TABS-001 |
| UX-06 | Assumptions that block correct UX are listed as needs-info | P1 process | Validation loop |
| UX-07 | Craft preferences (borders, centering, floating labels) do not override P0 | P0 process | P0–P7 hierarchy |

Related CANDIDATE principles (not CORE gates): FORM-FEEDBACK, TEXT-ALIGN, BORDER-RESTRAINT — note only, do not fail CORE bar solely on these.
